## ما هو MassiCloud؟

MassiCloud هو منصة Backend-as-a-Service سيادية مبنية للمطورين والشركات الجزائرية. Postgres مُدار، تخزين متوافق مع S3، ونظام مصادقة متكامل — يعمل بالكامل على الأراضي الجزائرية، ومتوافق مع القانونين 18-07 و25-11.
