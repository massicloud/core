يتمحور MassiCloud حول مجموعة صغيرة من الأفكار الأساسية. فهمها يجعل كل شيء آخر واضحًا.

## المشاريع

**المشروع** هو الحاوية الرئيسية. مشروع واحد لكل تطبيق. يمتلك:

- **قواعد بيانات** واحدة أو أكثر (Postgres) ومثيلات **Redis**
- **حاويات تخزين** للملفات
- **مفاتيح API** (anon + service)
- **مستخدمون نهائيون** (عملاء تطبيقك)

[المشاريع وقواعد البيانات ←](/ar/concepts/projects-databases)

## قواعد البيانات

كل قاعدة بيانات هي مثيل Postgres مُدار مع REST API مُولَّد تلقائيًا عبر PostgREST. تتفاعل معها عبر SDK أو مباشرةً عبر HTTP. يمكنك أيضًا الاتصال بأي عميل Postgres للترحيل والاستعلامات وغيرها.

## المصادقة

ثلاثة أدوار تحكم كل طلب: `anon` و`authenticated` و`service_role`. الدور المُطبَّق يعتمد على المفتاح وJWT المُرسلَين مع الطلب.

[المصادقة ←](/ar/concepts/authentication)

## Row Level Security

الوصول إلى البيانات يتحكم فيه سياسات RLS في Postgres. قاعدة البيانات نفسها تطبّق من يمكنه القراءة والإدراج والتحديث والحذف — لا كود تطبيقك.

[Row Level Security ←](/ar/concepts/rls)

تبقى جميع البيانات في الجزائر. لا نقل عبر الحدود. متوافق مع القانونين 18-07 و25-11 بنيويًا.
