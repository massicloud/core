---
title: السيادة والقانون الجزائري
description: لماذا وُجد MassiCloud، وكيف يمتثل للقانونين 18-07 و25-11.
---

وُجد MassiCloud لأن الشركات الجزائرية لم تعد تستطيع استخدام السحابات الأجنبية بأمان للبيانات الشخصية. تشرح هذه الصفحة السياق القانوني وكيف بُني MassiCloud ليفي بمتطلباته.

## القوانين ذات الصلة

- **القانون 18-07 (يونيو 2018)** — قانون حماية البيانات التأسيسي في الجزائر. ينشئ ANPDP (الهيئة الوطنية لحماية البيانات الشخصية)، يُعرّف البيانات الشخصية، يُحدد متطلبات الموافقة، إشعار الاختراق (5 أيام)، وحقوق أصحاب البيانات.

- **القانون 25-11 (يوليو 2025)** — تعديل رئيسي. يُلزم بتصريح ANPDP لأي شركة تتعامل مع البيانات الشخصية. عقوبات تصل إلى 1,000,000 دج ومسؤولية جنائية لعدم الامتثال. يُقيّد بشدة نقل البيانات عبر الحدود.

معًا تعني: **تخزين البيانات الشخصية للجزائريين على AWS أو GCP أو Azure أو Supabase أو أي خدمة أجنبية أخرى هو الآن خطر قانوني على الشركات الجزائرية.**

## كيف يستوفي MassiCloud هذه القوانين

| المتطلب                                | كيف يتعامل معه MassiCloud                                     |
| --------------------------------------- | --------------------------------------------------------------- |
| إقامة البيانات في الجزائر               | جميع قواعد البيانات موجودة فيزيائيًا في مراكز البيانات الجزائرية |
| دعم تصريح ANPDP                         | مخطط امتثال مدمج (`compliance.data_registry`، إلخ)             |
| تتبع الموافقة                           | جدول `compliance.consents` مدمج                                |
| إشعار الاختراق (المادة 38)              | جدول `compliance.breaches` مدمج للتسجيل                        |
| سجل التدقيق                             | مخطط `audit` اختياري يُفعَّل لكل قاعدة بيانات                  |
| منع النقل عبر الحدود                    | مستحيل بنيويًا — البيانات لا تغادر الجزائر                     |
| التشفير أثناء التخزين والنقل            | TLS 1.3 بين العميل وAPI؛ SSL بين API وقاعدة البيانات           |

## ما يعنيه هذا لك كمطوّر

تكتب تطبيقك. تستخدم MassiCloud. بياناتك لا تذهب إلى حيث لا ينبغي، تطبيقك يصبح أسرع (زمن استجابة أقل للمستخدمين الجزائريين)، وتحصل على قصة امتثال قانوني مدمجة في مكدسك.

لا تزال تحتاج أن تقوم **بجزءك** من الامتثال:

- تصريح معالجتك لـ ANPDP إذا كان مطلوبًا لقطاعك
- امتلاك سياسة خصوصية
- تلبية طلبات أصحاب البيانات (نوفر الأدوات)

ما لا يلزمك فعله: الاستعانة بمحامٍ لاختيار الاستضافة. طبقة السحابة سيادية بالبناء.
