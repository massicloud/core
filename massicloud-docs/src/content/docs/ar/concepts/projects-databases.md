## المشاريع

المشروع هو وحدة التنظيم الرئيسية في MassiCloud. فكّر فيه كتطبيق واحد. المشروع يمتلك:

- قواعد البيانات (Postgres, MySQL) ومثيلات Redis
- حاويات التخزين
- مفاتيح API (anon وservice)
- حسابات المستخدمين النهائيين

عادةً تنشئ مشروعًا واحدًا لكل تطبيق. إن احتجت بيئات staging وproduction، أنشئ مشروعَين — أو استخدم قاعدتَي بيانات في مشروع واحد.

## مفاتيح API

عند إنشاء مشروع، يُولَّد مفتاحان:

| المفتاح | البادئة | الغرض |
| ------- | ------- | ------ |
| مفتاح anon | `mc_anon_` | المتصفح / التطبيقات المحمولة. خاضع لـ RLS. |
| مفتاح service | `mc_service_` | جانب الخادم فقط. يتجاوز RLS. |

مفتاح service يُعرض **مرة واحدة** عند الإنشاء. خزّنه في مدير الأسرار فورًا.

## قواعد البيانات

كل قاعدة بيانات في المشروع هي إما مثيل Postgres أو مثيل [MySQL](/ar/concepts/mysql) — يُختار عند الإنشاء. يمكنك امتلاك قواعد بيانات متعددة في مشروع واحد، من أي من النوعين.

### مخطط `auth`

مخطط `auth` وكل ما يتعلق به (RLS، `auth.uid()`، إلخ) ينطبق على قواعد **Postgres**. قواعد MySQL تستخدم نموذجًا أبسط بدورين — راجع [المصادقة: مثيلات MySQL](/ar/concepts/authentication).

عند تفعيل مخطط المصادقة، ينشئ MassiCloud:

- `auth.users` — المستخدمون النهائيون لتطبيقك
- `auth.sessions` — الجلسات النشطة
- دوال مساعدة: `auth.uid()`، `auth.role()`، `auth.email()`

### مخطط `public`

جداول تطبيقك تعيش هنا افتراضيًا.

### Redis

قواعد بيانات Redis متاحة للتخزين المؤقت وpub/sub وتحديد معدل الاستخدام. اتصل بها عبر مكتبات عميل Redis القياسية.
