يرشدك هذا الدليل للبدء باستخدام MassiCloud في حوالي 10 دقائق. في النهاية، ستكون قد:

- أنشأت حسابًا في MassiCloud
- أنشأت مشروعًا بقاعدة بيانات تعمل
- أجريت أول استدعاء API من JavaScript

## ما ستحتاجه

- حاسوب مثبّت عليه Node.js 18 أو أحدث
- محرر كود
- الفضول، بالدرجة الأولى

## ما يوفره لك MassiCloud

MassiCloud هو Backend-as-a-Service موجّه الرأي. بدلًا من تجميع المصادقة وقاعدة البيانات والتخزين بنفسك، تحصل على الثلاثة في منصة واحدة متكاملة:

- **Postgres أو MySQL مُدار** — كل مشروع يحصل على قاعدة بيانات Postgres افتراضيًا مع REST API مُولّد تلقائيًا؛ أضف قواعد [MySQL](/ar/concepts/mysql) بجانبها متى احتجت
- **المصادقة** — سجّل مستخدميك وادخلهم ببضعة استدعاءات SDK، مع JWT و Row Level Security مدمجَين
- **تخزين الكائنات** — حاويات متوافقة مع S3 للملفات مع URLs مُوقَّعة مسبقًا
- **السيادة** — تبقى جميع البيانات في مراكز بيانات جزائرية، متوافقة مع القانونين 18-07 و25-11

النموذج الذهني مشابه لـ Firebase أو Supabase، لكنه محلي. SDK مصمَّم ليكون قريبًا من Supabase عمدًا، فإن كنت قد استخدمته، ستجد API مألوفة.
