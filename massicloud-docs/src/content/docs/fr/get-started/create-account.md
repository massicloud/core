<Steps>

1. **Rendez-vous sur [app.massicloud.dz](https://app.massicloud.dz)**

   C'est le portail MassiCloud — l'interface web pour gérer vos projets.

2. **Cliquez sur "S'inscrire"**

   Saisissez votre email et un mot de passe. Aucune carte bancaire n'est requise ; le niveau Hobby est gratuit pour toujours.

3. **Vérifiez votre email**

   Cliquez sur le lien dans l'email que nous vous envoyons. (Si vous ne le recevez pas dans la minute, vérifiez vos spams.)

4. **Vous y êtes**

   Vous arriverez sur votre tableau de bord — vide pour l'instant. Ensuite, nous créerons un projet.

</Steps>

## Note sur les régions

MassiCloud opère uniquement dans des datacenters algériens. Il n'y a pas de sélecteur de région car il n'existe qu'une seule région : l'Algérie. Vos données résideront physiquement à Alger.
