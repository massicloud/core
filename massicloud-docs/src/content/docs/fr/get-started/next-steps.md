## Construire quelque chose de réel

Le chemin le plus rapide de "première requête" à "vraie app" :

1. Ajoutez quelques tables dans l'explorateur
2. Activez RLS sur chacune (c'est activé par défaut)
3. Ajoutez des politiques adaptées à votre modèle auth
4. Connectez signup/login dans votre frontend
5. Utilisez `massi.from(table)` pour tout
